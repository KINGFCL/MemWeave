# MemWeave 总览：这是你的长期记忆

这是你的长期记忆，不是搜索引擎。这里没有相似度检索，也没有关键词索引。能不能想起一件事，靠你自己从目录出发沿关联走图，读完节点后自己判断。

## 记忆长什么样

**节点**是一条知识，你能控制的只有五项：

| 字段 | 含义 |
| --- | --- |
| `id` | 节点地址，创建后不能改 |
| `title` | 标题，一眼看出在讲什么 |
| `desc` | 你的理解，是记忆的主体 |
| 证据 | 你凭什么知道：来自哪段原文，或者由哪些节点推出 |
| `related` | 读到这里，还该接着看什么 |

**有两种关系，互不相干：**

- `related` 管导航，决定这条知识找不找得到。它是单向的。你希望反过来也能走到，就自己再 `link` 一次。
- `based_on` 管逻辑，决定这个结论是否还站得住。

所以还有结论依据的节点不能删，而关联断了只是可能找不到。

**总表是目录，不是索引。** 它按知识领域分成板块，每个板块有名字、描述和几个代表节点，其他节点都靠 `related` 到达。代表只是入口：它本身答不了问题，不代表这个领域没有答案。

**原文不可变，记忆可以改。** 原文按内容哈希存放，存进去就改不了。你的理解错了就改描述；原文错了或过时了，就存一段新原文，让节点改为引用它。

**证据是你推理的依据。** 描述是你当时的理解，可能有错。重要结论不要只看描述，要用 `evidence` 沿着依据一路追到原文。

**总表也是你的工作台。** 上面除了知识的领域，还有工作板：目标、步骤和做到哪了，以及最近做过什么。第一次工具调用和它们变化时，结果会附带这些内容，要再看一遍就用 `catalog show`。见 `manual-work`。

**时间由系统记录。** 每次修改都进时间线，节点也有创建和更新时间。你改不了，所以能用来判断新旧。
