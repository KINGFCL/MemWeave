# 报错怎么处理

**报 `E0xx`、`E1xx`、`E2xx`、`E3xx` 时，整段脚本都没有执行，记忆完全不变。** 一次会报告所有错误，并尽量给出提示。按提示全部改好后，**重新提交整段脚本**，不要拆开提交，否则会失去“全部生效或完全不生效”的保证。

| 错误码 | 含义 | 怎么做 |
| --- | --- | --- |
| `E001`–`E003` | 无法识别的字符，或者引号没有结束 | 检查引号。内容里有引号时用 `"""`，开头和结尾的引号数量要相同 |
| `E101` | 没有这条指令 | 按提示改，或者读 `language` |
| `E102` | 这个位置缺东西 | 按提示补上 |
| `E103` | `add` 或 `source` 没有写 `end` | 补上 `end` |
| `E104` | 写了不认识的子句 | 按提示改 |
| `E105` | 子句写了多次 | 只留一个 |
| `E106` | 一行多写了内容 | 每条语句单独一行。如果多出来的是文字内容，说明里面有三个连续的引号，用四个引号包住整段 |
| `E109` | `depth` 或 `limit` 超出范围 | 改到提示的范围内 |
| `E201` | 节点不存在 | 看提示。可能写错了，也可能被前面的语句删除了 |
| `E204` | 节点地址不合法 | 只用字母、数字、汉字、`-` 和 `_` |
| `E205` | 节点已经存在 | 换地址，或者用 `set` 修改已有节点。先确认是不是同一件事 |
| `E206` | 标题、描述、原文或名字为空 | 补上内容 |
| `E207` | 没有任何证据 | `add` 要写 `based_on`；`source` 要有原文；去掉证据前先加上新的 |
| `E208` | 新节点走不到 | 同一段脚本里写 `related_by`、`link` 或 `catalog add` |
| `E209` | 来源无效 | 地址和范围抄 `show` 的输出，不要自己算 |
| `E210` | 关系已经存在 | 不用再写，删掉这条语句 |
| `E211` | 关系不存在 | 用 `show` 查现有的关系 |
| `E212` | 证据会形成循环 | 结论必须能追溯到原文，不能互相依据。这是真正的逻辑问题，不要绕过 |
| `E213` | 还有结论依据这个节点 | 先给它们换依据，或者一起删除 |
| `E214` | 板块不存在 | 用 `catalog show` 查，或者 `catalog create` 新建 |
| `E215` | 板块已经存在 | 换名字，或者用已有的板块 |
| `E216` | 导出目标不可用 | 换一个不存在的目录或空目录 |
| `E217` | 有节点走不到，不能导出 | 接入或删除列出的节点，写在 `export` 前面 |
| `E301` | 只读工具不能改记忆或导出 | 改用 `memory_write` |
| `E302` | 脚本太大 | 拆成几段。先确认拆开后每段单独执行也没问题 |

**下面三种是执行时才发生的，规则不同：**

| 错误码 | 含义 | 怎么做 |
| --- | --- | --- |
| `E901` | 读取原文失败，其他语句照常执行 | 原文可能损坏。告诉用户，不要改记忆来掩盖 |
| `E902` | 导出失败，目标目录不变，其他语句照常执行 | 告诉用户原因。**已经执行的修改不要重复提交** |
| `E900` | 写入中途失败，通常是内存不足 | 输出写明了哪些语句已经生效。告诉用户，不要盲目重试 |

## 工具调用本身失败

服务连不上或者工具调用没有返回时，不能确定修改是否已经生效。先用 `memory_read` 查看相关节点，再决定要不要重新提交。
